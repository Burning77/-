# 本地验收记录

日期：2026-10-21。当前实现为 C++ / Qt Widgets Windows 版本。

## 已验证

- Qt 6.11.2 / MinGW 13.1 / CMake / Ninja Debug 构建通过。
- 10 个 Qt Test / CTest 套件通过，包含中文 SSE 跨字节分块、SQLite 重开与修订、服务配置隔离、请求来源隔离、取消队列、PCM 转换、WAV 头、转写去重与未完成状态、原生 WebSocket、本机 HTTP 流和窗口启动。
- 对暂停后快速重启时的迟到音频编写了失败测试，加入采集批次校验后通过。
- 本机 HTTP / WebSocket 使用真实回环服务器，不代表 OpenAI 或 DeepSeek 的云端调用通过。
- Qt Widgets 界面离屏截图已检查，中文可读、控件可见。

网络回环测试需要允许本机 TCP 连接的运行环境。受限沙箱内测试会超时，在允许本机网络的执行环境中通过。

## 发布包

Release 打包与独立运行检查进行中；最终结果在完成后补充。

## 尚未验证的真实场景

- 用户实际会议软件和耳机上的双路录音、设备热插拔及长时间采集。
- 有效 OpenAI 语音转写 Key、GPT 文本 Key 和 DeepSeek Key 的真实云端联调。
- 真实中文面试中的识别准确率、端到端延迟与回答质量。

API 凭据由用户在软件“设置”中填写，未要求在聊天中发送密钥。软件提供文本和转写连接测试。

## 实现调整

- 实时转写采用 Windows WinHTTP WebSocket。Qt WebSockets 的可选源码构建在本机工具链中异常终止，最终程序不依赖该组件。
- 中文源码路径下 Qt moc 无法创建生成文件，构建脚本使用专用英文源副本；源码仍在原工程目录。
- 业务实体以带稳定 ID 和来源字段的 JSON 记录存入 SQLite 索引表。
- 长会话按有界对话段生成分段复盘报告；超过单段上下文的输入会标出不完整。

## 使用限制

- 回环录音是所选播放设备的混音，可能包括其他软件的声音。
- 远端/麦克风是通道来源，不是声纹识别；时间位置为近似值。
- 自动提取、回答和复盘需要网络及正确的模型/API 权限。
- 实时问题识别与音量门限需要结合实际设备评估；可手动修正转写、问题并重试。
