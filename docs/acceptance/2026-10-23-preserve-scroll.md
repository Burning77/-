# 0.5.2 阅读位置与自动跟随验证

用户要求默认自动跟随新内容，向上翻阅时停止强制跟随。旧问题列表每次刷新都会清空重建，并把已选条目滚入视野；旧实时对话把距离底部三条以内也当作底部，导致上翻一条后仍被拉回。

新逻辑在刷新前分别保存两个列表的横向、纵向位置，严格按是否处于底部决定自动跟随。重建和恢复选中项后，先完成条目布局，再恢复视野。向上翻阅后，后续追加和无新增条目的刷新保持当前位置；回到底部即恢复跟随。切换会话显示目标会话的最新内容。手动添加问题仍会选中刚提交的问题。

- 先增加回归测试，在旧实现上复现 4 项失败：问题列表的中间和底部上一条位置被拉回；实时对话的底部上一条位置被拉回；问题列表原本位于底部时不能继续跟随新增问题。
- Release 应用、窗口测试和会话测试构建通过。完整 tst_window 27 项、tst_session 13 项 QtTest 检查通过，0 失败、0 跳过。
- 新增用例覆盖两个列表、中间及只上翻一条的位置、长文本换行、横向位置、保持原选中项、连续追加、无新增条目刷新、默认跟随、回到底部恢复跟随及切换会话。
- 限制 PATH 为运行包与 Windows 系统目录，外置 Qt6Test/qoffscreen 辅助程序使用 0.5.2 运行包依赖，14 项检查通过。
