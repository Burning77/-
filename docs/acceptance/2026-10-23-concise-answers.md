# 0.5.1 简短口述回答验证

用户要求参考回答采用面试者自己的视角，直接作答、省去分析过程。原 answer 提示词明确要求 3 至 5 要点、原理、例子、追问及填空式框架，这是冗长教练式输出的直接来源。

新公共提示词要求中文第一人称口述，默认 2 至 4 句、约 80 至 160 字，直接给结论与必要理由；省去标题、编号、分析过程、表达框架和追问预测。题目明确要求展开、举例或代码时可增加最少必要内容。仍要求不虚构个人经历、职责或测试数据，资料不足时给通用方案或一句确认。问题提取和复盘提示词未改变；历史回答需重新生成才采用新规则。

验证：

- 对 OpenAI、ChatGPT、DeepSeek 新增回答请求契约测试，旧提示词上 3 个用例失败，修改后通过。
- Release 构建通过；logic / preparation / session / textclient / window 共 5 组回归、66 项 QtTest 检查通过，无失败或跳过。
- 限制 PATH 为运行包与 Windows 系统目录，使用外置 Qt6Test/qoffscreen 辅助程序：回答逻辑 10 项、空闲界面 3 项通过。
- 独立只读代码审查未发现 Critical / Important；确认 API Key 和账号登录路径均保留公共提示词。
- 7 个语音运行库、模型及词表文件与 0.5.0 SHA-256 一致；本轮未重复语音解码验证。ZIP 50 个文件条目读取通过，无账号凭据、会话数据库、录音或测试音频。

本次使用离线请求及本地 HTTP 模拟验证，没有读取真实账号凭据或调用线上推理服务。验证覆盖指令构造和会话/展示路径，不能保证模型每次都严格遵守字数；应在当前账号对旧问题点击“重新生成所选回答”查看新结果。
