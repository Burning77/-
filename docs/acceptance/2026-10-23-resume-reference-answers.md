# 0.6.1 结合本场简历的参考回答

0.6.0 新建会话已复制简历到 experience 字段，但回答函数没有直接读取 preparation.resume 快照，且只泛指经历摘要。现统一优先使用本场 resume.text 的完整文字与文件名；无简历时回退到本场旧 experience，再兼容 preparation.experience。不读取最新全局草稿，不改写历史会话背景。

共享回答指令明确优先结合与当前问题相关的简历项目、职责、技术和真实经历，不复述无关内容；保留参与、协助、负责的职责边界，不把参与说成主导。仍为第一人称、默认2～4句约80～160字、直接口述、不输出分析过程，不虚构成果或测试数据。自动回答、手动提问和重新生成使用同一公共构造函数，OpenAI、ChatGPT、DeepSeek均生效。已有回答需重新生成；旧会话保留其原背景。
