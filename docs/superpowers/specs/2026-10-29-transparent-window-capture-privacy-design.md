# 半透明界面与远程捕获排除设计

日期：2026-10-29。状态：用户已确认“按设计直接实现”，在当前对话内实施。

## 需求与现状

用户希望面试助手具有参考图片中的半透明背景，并提供按钮，让自己在本机仍能看到窗口，而通过向日葵连接的对方看不到。现有程序为 C++ / Qt Widgets 0.7.3，使用固定浅色背景、原生窗口边框及独立设置/准备对话框。

透明外观与捕获排除是两个独立功能。透明不会自动阻止截屏。向日葵官方“隐私屏”是使被控端本地屏幕黑屏，不能满足本需求；未找到官方保证其所有远控采集模式都遵守 Windows 窗口捕获排除的说明。

## 方案比较与推荐

- 推荐：仅背景使用半透明深色，文字与操作控件清晰；独立请求 Windows 捕获排除。符合参考外观与本机可见目标，但须补齐透明窗口的拖动、缩放、最小化/最大化/关闭及离屏恢复，并实测向日葵兼容性。
- 整个窗口统一降低不透明度：改动小、保留原生边框，但文字一起变淡，不作为推荐方案。
- 直接隐藏窗口或使用向日葵隐私屏：本机也无法正常查看，不符合用户明确的可见性要求。

用户已选择推荐方向；不将未确认的向日葵兼容性记作已支持。

## 交互

主界面增加“透明背景”开关、背景不透明度调节与“远程隐藏”独立开关。透明背景默认不透明度80%，允许40%至95%，普通模式恢复当前浅色界面。文字保持不透明，控件、对话与参考回答仍能正常阅读和操作。

透明模式使用 Windows 上 Qt 支持的透明窗口形式，提供拖动、边缘缩放及最小化/最大化/关闭操作，延续既有屏幕内恢复逻辑。切换外观不停止录音、不更换当前会话、不丢弃生成内容。

“远程隐藏”默认关闭，每次启动由用户主动开启。开启后本机窗口仍显示，向 Windows 请求 WDA_EXCLUDEFROMCAPTURE；只报告本机接口实际设置结果，界面不得显示“向日葵已验证隐藏”等未经实测的结论。开关旁说明“向日葵兼容性需实测”。关闭后恢复普通捕获行为。

捕获排除覆盖本软件的主窗口和能管理的应用内顶层对话框/弹窗。新窗口与原生句柄重建后重新应用；透明模式切换也需保持此状态。任一应用失败时明确显示未完全生效和错误，不能仅凭按钮已按下显示成功。原生系统对话框与第三方界面不能宣称自动受保护。

## 边界

Windows 捕获排除仅面向支持该接口的捕获方式。完整排除要求 Windows 10 2004 或更高版本；不支持或设置失败时显示不可用，不静默退回黑块遮挡模式。API设置成功不等于向日葵所有版本、驱动和采集模式均已验证。

不修改或注入向日葵，不安装捕获驱动，不修改 Windows 显示设置，不将本机窗口隐藏来冒充远端不可见，也不保证屏幕拍照等方式无法获取内容。

## 验证与交付

自动化覆盖透明背景与文字的独立透明度、模式切换及窗口操作、捕获排除开关/失败状态、新弹窗与句柄重建后的重新应用。原生接口检查只使用本程序创建的测试窗口，不读取实际账号、简历、面试音频或捕获用户桌面。

运行完整既有回归并打独立版本包，保留旧版。向日葵验收需要用户主动发起实际远控连接：本机确认窗口可见，另一端分别检查开启/关闭的画面，打开设置/准备窗口、切换透明模式并恢复窗口后重复确认。未完成该步骤前，交付说明明确标记“向日葵实际远控未验收”。
